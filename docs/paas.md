# PaaS

The project is containerized and can be deployed to a PaaS that supports Docker images and environment variables.

## Required Services

- PostgreSQL
- Redis
- Six application containers

## Required Variables

- `DATABASE_HOST`
- `DATABASE_PORT`
- `DATABASE_DB`
- `DATABASE_USERNAME`
- `DATABASE_PASSWORD`
- `REDIS_HOST`
- `REDIS_PORT`
